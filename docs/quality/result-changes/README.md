# 結果変更記録

基準結果（`qa/baselines/`）を 1 ビットでも変更する PR には、このディレクトリに連番記録を追記する（[QA-04](../quality-plan.md)）。`tools/qa/results.py accept --record NNNN` は該当記録ファイルの存在とその中のケース言及を確認してから更新を許可する。

ファイル名は `NNNN-<slug>.md`（`0001` から連番）。記録作成後は内容を上書きせず、訂正は新しい番号の記録として追加する。

## 様式

```markdown
# NNNN: 何が変わったか（一文）

- Date: YYYY-MM-DD
- Issue: #N
- Pull request: #N
- 原因の分類: 不具合の修正 ｜ 算法の変更 ｜ 精度の扱い ｜ 依存の更新 ｜ コンパイラ・フラグ・命令セット
- 仕様の ID: DES-XX, ...
- 承認: （所有者の名前と日付）

## 原因

何を変え、なぜ結果が変わるのか。

## 影響

| ケース | プラットフォーム | 量 | 変更前 | 変更後 | 相対変化 |

## 許容比較・数値予算との妥当性

## 出荷版・既存モデルへの影響

## 確かめたこと
```

## 記録

まだ結果変更記録は登録されていない。最初のプラットフォーム認定時（`numeric-canary` 初期登録）は新規基準作成として扱う。
